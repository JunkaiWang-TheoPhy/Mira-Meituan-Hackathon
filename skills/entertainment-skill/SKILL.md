# entertainment-skill

Mira uses this skill as a secondary demo lane for state-adapted local
entertainment. It is intentionally not the primary submission path because
instant retail demonstrates the hardest fulfillment loop.

## Trigger Events

- `weekend_low_energy`
- `weekend_high_energy`

## Tool Surface

- `inferEnergyMode(context)`
- `searchEntertainmentOptions(location, energyMode)`
- `createWeekendPlanPreview(option)`

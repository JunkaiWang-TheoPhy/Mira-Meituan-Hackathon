# 竞赛提交材料

## 作品名称

Mira：基于 OpenClaw 的本地生活私人管家

## 作品简介

Mira 是一个基于 OpenClaw 的本地生活全天候私人管家，不是“你问它答”的查询助手，而是能主动感知、主动判断、主动安排生活的生活版 Jarvis。它通过眼镜、手表和手机获取用户的场景、日程、身体状态和生活偏好，再通过 OpenClaw 风格的 Memory、Heartbeat、Skill 和 Gateway 机制，调用餐饮、即时零售、出行预约和娱乐推荐等本地生活能力，完成从“状态感知”到“推荐决策”再到“确认履约”的闭环。

当前 Demo 主推即时零售场景：当用户处于加班、身体不适或临时缺少生活用品等状态时，Mira 会结合用户常用清单、附近库存、配送时效和预算约束，主动生成一个补给方案，并在用户确认后完成模拟下单、配送 ETA 展示和预算记录。我们同时实现了餐饮推荐、日程出行提醒和周末娱乐安排等扩展场景，展示 AI 从“更聪明的搜索框”走向“真的会替你过日子的生活管家”的可能性。

## 口号

工作交给别的工具，生活由 Mira 帮你安排，美团负责把事办成。

## 技术亮点

- 基于 Heartbeat 的主动触发，而不是等待用户搜索。
- 基于 Memory 的生活偏好、忌口、预算、常用地址和常用商品。
- 基于 Skill 的本地生活能力封装：餐饮、即时零售、出行、娱乐、预算。
- 基于 Bridge/Safety Layer 的确认、预算、隐私和履约边界。
- Mock 美团服务完整覆盖 POI、库存、配送 ETA、订单和履约跟踪。

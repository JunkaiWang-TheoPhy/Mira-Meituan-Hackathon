# 30 秒 Demo 视频脚本

## 0-5 秒

画面：评委控制台显示用户状态。

旁白：Mira 不是搜索助手，而是基于 OpenClaw 的本地生活管家。

## 5-12 秒

画面：Heartbeat 触发，识别晚间加班、低能量、下雨、长时间未离开。

旁白：它通过手表、手机、日程和位置理解你当前的生活状态。

## 12-20 秒

画面：Skill selected = `instant-retail-skill`，补给清单、库存、ETA、预算出现。

旁白：Mira 结合常用清单、附近库存、配送时效和预算，准备一个可确认的补给方案。

## 20-27 秒

画面：Policy gate 要求确认，用户回复“好”，mock order created。

旁白：涉及金钱和敏感上下文时，Mira 必须等待确认。

## 27-30 秒

画面：Budget updated，Delivery ETA 28 minutes。

旁白：Mira 负责懂你，OpenClaw 负责调度，美团负责办成。
